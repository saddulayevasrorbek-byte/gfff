# Quiz App

A browser-based quiz application built with HTML, CSS, and JavaScript.

## Project

This project was built as part of the roadmap.sh frontend projects track.

https://roadmap.sh/projects/quiz-app

## Features

- 10 multiple-choice questions
- Instant feedback (green = correct, red = wrong)
- Score tracking
- Progress bar
- Final results screen
- Play again button

## How to Run

Just open `index.html` in your browser — no setup needed!

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
